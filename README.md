# Hubster

Downloads for **Hubster**, a desktop app for your Google accounts: Drive sync, Calendar, Email, Tasks, Chat and Ask (AI).

## Install

Get the files from the **[latest release](https://github.com/djacky/hubster-releases/releases/latest)**:

- **Linux** (64-bit, with .deb packages — Ubuntu, Debian, Mint…): download `hubster_<version>_amd64.deb`, then run

  ```bash
  sudo apt install ./hubster_<version>_amd64.deb
  ```

  and open Hubster from your app menu.
- **Windows 10/11** (64-bit): download and run `hubster-setup-<version>.exe`. If Windows says "Windows protected your PC", choose **More info → Run anyway** (the installer isn't code-signed yet). No administrator rights needed.

## Signing in

Google shows "Google hasn't verified this app" the first time: choose **Advanced → Go to Hubster (unsafe)** to continue.

## Updates

Hubster updates itself. When a new version is out it shows a notification: click **Update**, and it installs and reopens. Every update is signed, and Hubster checks the signature before it installs anything.
